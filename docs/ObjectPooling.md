# 오브젝트 풀링 전략

## 적용 대상

- 반복 생성되는 전투 이펙트
- 데미지 텍스트와 HUD 요소
- 짧은 수명의 투사체
- 반복 등장하는 몬스터 또는 UI 항목

## 설계 원칙

- 모든 객체를 무조건 풀링하지 않습니다.
- 생성 비용과 사용 빈도를 측정해 적용합니다.
- `OnRent`와 `OnReturn`에서 상태를 완전히 초기화합니다.
- 최대 보유 수와 유휴 정리 정책을 둡니다.
- 풀 오염을 막기 위해 반환 중복을 검증합니다.

## 위험

풀은 GC를 줄일 수 있지만 사용량보다 과도하게 보유하면 메모리를 증가시킵니다. 에셋 핸들 수명과 인스턴스 수명을 분리해 관리해야 합니다.
