# 메모리 및 GC 최적화

## 문제 유형

- 이벤트 구독과 Static 참조로 인한 Managed 객체 유지
- Addressables 해제 누락과 Unity Native 객체 유지
- Texture·Mesh·Audio의 과도한 상주
- 임시 컬렉션, 문자열, Closure로 인한 GC Alloc
- 제한 없는 풀과 캐시로 인한 장시간 메모리 증가

## 분석 절차

1. 재현 시나리오와 목표 기기를 고정합니다.
2. 특정 콘텐츠를 반복 진입·이탈합니다.
3. Memory Profiler Snapshot을 비교합니다.
4. Managed와 Native 참조 체인을 분리해 확인합니다.
5. 수정 후 동일 반복 횟수와 조건으로 재측정합니다.

## 개선 원칙

- 소유자가 명확하지 않은 참조를 만들지 않습니다.
- 캐시와 풀에는 상한·정리 시점·진단 정보를 둡니다.
- Update 경로의 임시 할당을 제거합니다.
- 로드 완료 프레임의 대량 인스턴스 생성을 분산합니다.
- 메모리 감소뿐 아니라 프레임 타임 변화도 함께 확인합니다.
