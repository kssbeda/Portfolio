# 라이브 서비스 운영 원칙

## 핵심 관점

라이브 서비스 코드는 정상 흐름보다 실패 후 복구 가능성이 중요합니다. 패치, 네트워크, 서버 데이터, SDK 변경이 계속 발생하므로 진단과 우회 경로를 설계에 포함합니다.

## 운영 체크리스트

- 기능을 안전하게 비활성화할 수 있는가?
- 서버 데이터 오류가 전체 클라이언트 오류로 확산되지 않는가?
- 재접속 후 보이는 화면이 권위 상태와 일치하는가?
- 장시간 플레이 시 메모리가 안정적인가?
- 로그만으로 사용자 시나리오를 추적할 수 있는가?
- 핫픽스 시 변경 범위를 최소화할 수 있는가?

## 배포 후 관찰

크래시, 재접속 실패, 로딩 지연, 메모리 상승, 특정 기기 발열, 결제·SDK 오류를 우선 관찰합니다. 문제가 발생하면 사용자 영향과 재현 가능성을 기준으로 우선순위를 정합니다.
