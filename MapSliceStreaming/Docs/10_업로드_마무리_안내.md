# 오늘 업로드를 마무리하는 방법

**문서와 공개 예시 코드는 GitHub에 게시. APK 바이너리는 PC에 있는 성공한 빌드를 별도로 업로드해야 합니다.**

1. Unity가 마지막으로 정상 빌드하고 Samsung 기기에서 Terrain 표시가 확인된 `.apk` 파일을 찾습니다. 최신 안개/탐험 튜닝을 오늘의 성공 빌드인 것처럼 합치지 않습니다.
2. [Releases](https://github.com/kssbeda/Portfolio/releases)에서 **Draft a new release**를 선택합니다.
3. 태그: `v5.4.2-android-demo-20261026`; 제목: `MapSliceStreaming Android 개발 빌드 — 2026-10-26`.
4. Attach binaries 영역에 **실제 APK 파일**을 첨부하고 아래 설명을 입력한 후 **Publish release**를 누릅니다.
5. 파일이 다운로드되는지 확인하고 필요하면 프로젝트 README의 Releases 링크를 특정 릴리스로 바꿉니다.

### Release 설명 예시

```text
Unity 6000.3.24f1 / URP / Addressables 기술 데모
검증 기기: Samsung SM-F958N / Android 17 / Adreno 750 / Vulkan
Android Terrain GPU Instancing을 비활성화하여 근거리 Terrain 렌더링 정상화 확인
개발용 APK — 디버그 UI가 포함될 수 있고 모든 기기·장시간 테스트는 미완료
전체 Unity 프로젝트 소스와 Bake 도구는 비공개
```

파일 무결성은 PowerShell의 `Get-FileHash -Algorithm SHA256 "파일경로.apk"`로 확인할 수 있습니다.
