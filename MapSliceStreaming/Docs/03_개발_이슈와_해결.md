## 2026-10-26 Android Terrain 분석

Unity Editor에서는 Terrain이 보이지만 Android APK에서는 가까운 지형만 사라지는 문제를 재현했습니다. `drawHeightmap=True`, `shaderSupported=True`, `cameraLayer=True`, `holeFilled=True`와 Collider 존재를 확인했고, Proxy를 숨기면 먼 지형의 HLOD Skirt가 따로 사라졌습니다.

Full Terrain 등록 코드가 GPU Instancing을 강제 활성화하는 것을 확인해 Android에서만 해제했습니다. 이후 **SM-F958N / Android 17 / Adreno 750 / Vulkan**에서 정상적인 지형 표시를 확인했습니다. 엔진 자체 결함으로 단정하지 않습니다.

### 별도 관찰

`Gralloc4 format 59` 경고는 지형이 정상 표시되는 빌드에서도 발생했습니다. `AssetBundle.Unload`를 동반한 일시적 빌드 실패는 Editor 재시작 후 성공했지만 원인 확정 전입니다. Logcat 한글 깨짐은 로그 수집 인코딩 문제로 따로 관리합니다.
