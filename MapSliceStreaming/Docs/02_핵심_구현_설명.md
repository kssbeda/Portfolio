# 핵심 구현과 설계 판단

## Full / Proxy

근거리 충돌·경로 데이터가 필요한 영역은 Full Terrain, 원거리는 경량 HLOD/Proxy로 표시합니다. 플레이어 주변 필수 청크의 생명주기를 우선하고 원거리 표시 예산을 조정합니다.

## 이동 안전성

TerrainCollider 준비 시점 확인, 수면/해안 경계 검사, 급경사·지형 구멍·나무 줄기 장애물 처리를 분리했습니다. 수면 접근은 전방 검사 거리 0.12m를 기준으로 실제 차단 로그 `앞높이=6.024, 기준=6.025`를 확인했습니다.

## 탐험/지도

전체 맵 텍스처는 청크 수명과 분리하고, 탐험 마스크 및 발견한 이정표 상태를 보존합니다. 목적지의 경로 품질은 NavMesh 검증 여부와 지형 기반 예측 여부를 구분합니다.

## Android 전용 호환성

청크 등록 시 모든 Terrain에 GPU Instancing을 활성화하던 경로가 있었습니다. Android에서만 `drawInstanced=false`로 바꾸고 실기기에서 Terrain 렌더링 정상화를 확인했습니다.
