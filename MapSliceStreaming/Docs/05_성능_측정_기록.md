# 성능 측정 원칙

실측하지 않은 최적화 성과 수치와 FPS 개선률은 기재하지 않습니다.

동일한 화면·카메라·그래픽 설정과 경로를 기준으로 Android 실기기에서 Full/Proxy 전환, 나무 충돌, 반복 순간이동을 비교하고 프레임 평균·P95/P99·GC Alloc·메모리·CPU/GPU 병목을 수집할 계획입니다.

| 테스트 | 평균 ms | P95 ms | P99 ms | 메모리 | 결과 |
|---|---:|---:|---:|---:|---|
| 기본 지형 | - | - | - | - | 미측정 |
| 나무/바위 포함 | - | - | - | - | 미측정 |
| 반복 이동·순간이동 | - | - | - | - | 미측정 |

**Android Terrain GPU Instancing OFF는 렌더링 정상화 조치이며, 성능이 개선됐다는 뜻은 아닙니다.**
